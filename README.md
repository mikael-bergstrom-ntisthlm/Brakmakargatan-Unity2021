# Bråkmakargatan
Ett enkelt slagsmålsspel byggt för användning i undervisning i animation, främst på gymnasiet.

## Kontroller
Det finns en *animation* för blockeringar, men ingen kod (ännu).

### Spelare 1 (vänster)
* Vänster/höger: A/D
* Hopp: W
* Slå: F
* Sparka: T

### Spelare 2 (höger)
* Vänster/höger: ←/→
* Hopp: ↑
* Slå: L
* Sparka: P
